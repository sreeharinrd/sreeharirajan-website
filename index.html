LISA — Lifecycle Inspection, Security & Analytics

"An airport security scanner for APIs: finds slow APIs, weak spots and memory issues before production."

Problem

API performance bottlenecks, weak spots, and SLA misses were historically caught late in pre-production.

Approach
  • Parses OpenAPI/Swagger specs to automatically synthesize positive and negative HTTP test cases
  • Executes configurable load testing with real-time RPS, latency distribution (P90/P95/P99), and failure analytics
  • Generates automated release readiness reports with actionable SLA and performance recommendations

Outcome: SLA issues caught on 10 APIs in the first 2 months.

Multi-Stream Live Broadcasting Platform

Self-hosted distributed RTMP live-streaming pipeline for SreeStories YouTube & creator channels.

Problem

Simultaneous live-streaming to multiple platforms required high bandwidth and costly third-party SaaS services.

Approach
  • NGINX RTMP ingest server receiving low-latency broadcast feeds from OBS Studio

  • Spring Boot and Laravel control layer monitoring stream health telemetry and relay status
